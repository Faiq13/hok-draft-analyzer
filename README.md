# Honor of Kings (HoK) Draft & Counter Analyzer

Professional 5v5 Draft, Ban/Pick, and Real-time Counter Analyzer designed for Honor of Kings esports teams, coaches, and competitive players.

## ✨ Features

- **5v5 Ban/Pick Simulation**: Complete professional tournament draft phase simulator (Blue & Red sides, Ban & Pick rounds).
- **Multi-Hero Counter Algorithm**: Intelligent scoring engine that aggregates counter advantages and vulnerabilities against multiple enemy team picks simultaneously.
- **Dynamic Tactical Reasons**: Real-time contextual explanations (e.g. *"Efektif melawan Ao'yin & Ata"*) for every recommendation.
- **Strict Availability Filtering**: Automatically hides already picked or banned heroes from recommendation pools to prevent duplication errors.
- **Comprehensive Hero Roster**: Features over 120+ authentic Honor of Kings heroes with local `.webp` avatars, role categorizations (Roam, Clash, Mid, Farm, Jungle), and tactical metadata.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Faiq13/hok-draft-analyzer.git
   cd hok-draft-analyzer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
